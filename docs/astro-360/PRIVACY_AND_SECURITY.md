# Privacy and deployment

Never deploy feature refs. Pages retain/configure/upload/deploy require refs/heads/main AND push or workflow_dispatch. Audit CI runs separately without pages permissions. No merge or main update authorized.

Public packaging is an explicit git-tracked source allowlist plus new sanitized validation evidence. Exclude _local_audit, raw private archives, result exports and machine absolute paths. Check credential patterns and known private locations before upload. Public synthetic fixtures and official public reference sites are labeled. A structural sanitization check is not a proof that arbitrary future tracked text is free of personal information; review additions.

Map tiles and official elevation requests communicate requested map area to external services. Coordinates are kept out of analytics and URLs generated by this application; local exports deliberately include coordinates. Existing browser source cache holds downloaded tile footprints. Clear it through the original interface if required.
