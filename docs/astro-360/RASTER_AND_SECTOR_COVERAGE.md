# Coverage and missing data

Sampled ray scans still carry UNKNOWN/INCOMPLETE and retain attempted/valid counts, errors, sampled extent and cyclic gaps. Exhausted angular scans are broken in Cartesian and polar graphics; the 240° unexamined closing arc is not drawn as a measured curve. Ray lattice coverage is never sufficient for NINA.

NativeCellSource streams original GeoTIFF block pixels with strict existing EPSG25832/PixelIsArea geometry checks, then uses each value's full bilinear influence support. Closed boundary contacts are included. Original raw resolution and doubled support width are separate concepts. Cell sectors retain evaluated counts, missing supports, knownCellUpper for observed subsets, and modelUpper only after complete traversal and no missing support in that sector. Source error/cell budget invalidates every full-sector bound; native height outside supported range is unknown.

CONDITIONAL_MODEL_BOUND means the complete declared projected-raster scenario, NOT true geographic completeness or current-world visibility. NoData never becomes 0; unavailable modelUpper stays null even if knownCellUpper is finite. Ground uncertainty NoData blocks interval propagation. Native support traversal covers skinny raster-represented peaks between rays; it cannot recover objects absent from the data. Scientific release BLOCKED. NINA export DENIED for all supported schemas. Full geographic/physical coverage NOT_CERTIFIED; no on-site measurements. Current partial model and acceptance gates: ADR-0002-fail-closed-native-cells.md and ROUND2_STATUS.json.
