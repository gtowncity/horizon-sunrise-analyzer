# User guide

Open 360°-Horizont in the main navigation. Enter geographic coordinates or click/drag the map observer. Specify optical height above DGM1 or, in advanced inputs, absolute DHHN2016 optical height. Absolute height replaces the relative calculation. Choose FAST or DETAIL, terrain distance and separate DOM near radius. Larger DOM radii can exhaust budgets quickly. Start, observe tile/byte progress, cancel if needed.

Every curve is VORLÄUFIG. Blank values are UNKNOWN. Schraffur marks unresolved spatial/angular sampling. Select azimuth by keyboard numeric input, slider, chart or polar click; table and map select the nearest computed ray. Charts interpolate for visualization only. Scientific exports retain original points and coverage. User minimum (30° example, freely editable) and specified reserve alter planning only. NINA requires explicit acknowledgement; any entirely unknown requested source corridor blocks export.
