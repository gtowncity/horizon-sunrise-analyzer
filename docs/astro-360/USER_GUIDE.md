# User guide

Choose FAST for nominal overview or DETAIL for rays plus native-cell/interval analysis. Enter observer coordinates or move the map marker, choose relative optical height OR measured absolute DHHN2016 height. Set separate DGM/DOM radii, user minimum and nominal reference reserve. Advanced parameters expose continuous horizontal movement radius, optical lower/upper heights, assumed source error caps and native-cell budget. None are verified by defaults.

Compare the nominal true-north curve with the separately labelled projected model table; these are different proof levels. UNKNOWN modelUpper is never replaced by the known-subset value. A source/budget problem means incomplete investigation, even when the curve has numerical samples. Cancellation stops worker; remote job generation may continue. Local source cache survives.

JSON/CSV preserve evidence; SVG/PNG export graphics. NINA is intentionally unavailable until missing scientific/consumer gates are met; there is no checkbox bypass. Earlier NINA files from e6833ae cannot be treated as safe. Do not use them for automatic clearance decisions. Scientific release BLOCKED. NINA export DENIED for all supported schemas. Full geographic/physical coverage NOT_CERTIFIED; no on-site measurements. Current partial model and acceptance gates: ADR-0002-fail-closed-native-cells.md and ROUND2_STATUS.json.
