# Uncertainty budget

No measured physical accuracy established for 360°. Terrain stated product height accuracy better than ±0.20 m, local exceptions unresolved; DOM stated positional/vertical 0.4–0.6 m, not 0.2 m accuracy. Raster spacing is not an uncertainty bound. Nearby error dominates: atan(0.6/10)=3.43363036°, atan(0.6/100)≈0.34377055°. Angular sampling can miss a chimney entirely; no finite residual bound currently derived.

Observer location, measured eye height, optical entry motion, object distance, source age, current vegetation, k variation, datum/vertical deflection, interpolation and finite domain need separate controls. Position and vertical budgets are recorded but NOT propagated. Margin is user-specified, not verified. Never interpret default zero budgets as perfect knowledge. A safe camera-field claim is prohibited.
