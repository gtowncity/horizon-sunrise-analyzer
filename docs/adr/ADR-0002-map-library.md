# ADR-0002: MapLibre GL JS

Status: accepted, 2026-09-16.

## Context

Free interactive basemap with markers and analysis overlays.

## Decision

MapLibre with OSM raster source, attribution and separately bundled module worker.

## Alternatives and consequences

Leaflet is a good lighter alternative; MapLibre supports future vector/fan layers. No key-dependent basemap or tile bulk download.
