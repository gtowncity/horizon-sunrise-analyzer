# ADR-0005: Astronomy Engine

Status: accepted, 2026-09-16.

## Context

Browser-capable astronomical ephemerides with documented provenance.

## Decision

Astronomy Engine, independently crosschecked against NOAA and USNO.

## Alternatives and consequences

A simple hobby sunrise library would not provide the same model provenance or full disk primitives. Downloading large JPL ephemerides is disproportionate for the atmospheric error budget.
